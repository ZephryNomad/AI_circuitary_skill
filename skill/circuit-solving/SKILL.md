# 解电路题

## 这个技能解决什么问题

电路题的错误几乎不来自算术，来自**判读**：电压源极性读反、电流源箭头看错、受控源参考方向搞混、待求量的正方向没定。"习题 4-14"就是活例：受控源极性读反，P_max 从 108 W 变 84.5 W，R_eq 从 3 Ω 变 2 Ω —— 拓扑一模一样，只差一个符号。

所以本技能的分工是：

- **你（模型）负责判读**：把图变成一张文字卡，把每个参考方向写死。
- **机器负责计算**：`circuit.py` 用精确有理数解，并自己证明答案对（功率平衡、换参考点复算、戴维宁两条独立路径互校、网表往返）。

判读错了机器不会替你发现，但**计算错了机器一定会被自检拦住**。这就把可疑范围缩到唯一一个环节。

## 五步法（按顺序做，不要跳）

1. **判题型**：直流 / 相量 / 瞬态 / 逻辑。看题里有没有 ω、L、C、t、状态表。
2. **定参考方向**：先把五件事写下来（见下"必须问清的五件事"），写不全就先别算。
3. **写题目卡**：一行一个元件，**方向靠节点顺序表达**。`V Us 1 0 12V` 就是 V(1)−V(0)=12，1 是正极。
4. **跑机器**：`python circuit.py card 题.card`，看输出里的"校验"是否全通过。
5. **五段式回复**：答案 → 推导 → 网表 → 验算证据 → 判读敏感性。

## 必须问清的五件事（判读清单）

发图或口述题目时，这五项缺一项就先补问，不要靠猜：

| 项 | 为什么要问 | 卡里怎么表达 |
|---|---|---|
| 电压源的正极在哪端 | 反了答案整体差一个负号 | `V Us 1 0 12V` → 1 是正极 |
| 电流源的箭头朝哪 | 同上 | `I Is 0 1 2A` → 电流由 0 经源流向 1 |
| 受控源的参考极性（控制量的 +/−、受控量的 +/−） | 最容易读反，且错了仍然"自洽" | `E E1 3 0 0 2 100000` → 受控电压 V(3)−V(0)=A·(V(0)−V(2)) |
| 待求量的参考方向 | 决定答案的正负号 | `求: I(R3)` 取"由 n1 经 R3 流向 n2"为正 |
| 求什么（一个量 / 戴维宁三参数 / 最简式 / 状态表） | 决定跑哪个子命令 | `求: V(2)`、`端口: 2 3`、`形式: SOP` |

## 题型路由

| 题目长什么样 | 用哪个子命令 | 数值性质 |
|---|---|---|
| 只有 R、V、I、E/G/H/F，无 ω 无 L/C | `card` | **精确有理数**，答案形如 `500/9` |
| 有 ω 或 f，有 L/C，问稳态有效值/相位 | `ac` | 精确复数，形如 `1000/101 - 100/101i` |
| 问开关动作后的 u(t)/i(t)、时间常数、阶数 | `tran` | 浮点（指数逼近，必然如此） |
| 问最简与或式/或与式、卡诺图、触发器激励、状态转移 | `logic` | 精确、穷举验证 |

戴维宁/诺顿不是单独题型：在卡里加一行 `端口: a b`，`card` 子命令会自动补 u_oc、i_sc、R_eq，可再加 `--rl 3` 接负载算 P_L 与 P_max。

频响扫描：`ac 题.card --sweep 10,1e5,20`，输出 |V| 与相位随 ω 变化的表。

## 题目卡语法

```
题名: 戴维宁求最大功率
端口: 3 0
求: V(3)
V Vs 1 0 12V
R R1 1 2 4Ω
R R2 2 0 6Ω
R R3 2 3 2Ω
```

跑 `python circuit.py card 题.card --rl 3` 得到：u_oc = 36/5 V，i_sc = 18/11 A，R_eq = 22/5 Ω，P_max = 162/55 W，五项校验全通过。这张卡可以当"最小可跑样板"照抄结构。

### 元件行：类型 [名字] n1 n2 数值

| 类型 | 写法 | 含义 |
|---|---|---|
| `R` | `R R1 1 2 3Ω` | 电阻；**R=0 不许写**，短路用 0V 源 |
| `V` | `V Us 1 0 12V` | 独立电压源，V(1)−V(0)=12 |
| `I` | `I Is 0 1 2A` | 独立电流源，电流由 0 经源流向 1 |
| `E` | `E E1 3 0 0 2 10` | VCVS：V(3)−V(0) = 10·(V(0)−V(2)) |
| `G` | `G G1 3 0 2 0 0.5` | VCCS：由 3 经 G1 流向 0 的电流 = 0.5·(V(2)−V(0)) |
| `H` | `H H1 3 0 Us 2` | CCVS：V(3)−V(0) = 2·I(Us) |
| `F` | `F F1 4 0 Us 2` | CCCS：由 4 经 F1 流向 0 的电流 = 2·I(Us) |
| `C` / `L` | `C C1 2 0 1µF` | 电容 / 电感，只用于 ac 与 tran |

名字可以省略（自动编号 R1/V1/…）。写 `Us` 这种不以位号字母开头的名字会自动补成 `VUs`，但 `求: I(Us)` 仍然认。

**H/F 的控制量必须是一个具名独立电压源的电流。** 原题控制量若是某支路电流，就在那条支路串一个 0V 取样源把电流"引"出来——这是标准做法，不是取巧：

```
V VI1 5 0 0V      # 串在 5 与 0 之间，电流由 5 流向 0 为正
H H1 3 1 VI1 2    # 用 I(VI1) 当控制量
```

### 字段行：冒号前是关键字，冒号后是内容

| 字段 | 用途 |
|---|---|
| `题名:` / `题目:` | 标题 |
| `端口: a b` | 求戴维宁/诺顿，u_oc = V(a)−V(b)，i_sc 由 a 经短路流向 b |
| `求:` / `求取:` / `find:` | 待求量，可一行多个：`求: V(2) V(1,2) I(R1) I(Us)` |
| `备注:` | 自由备注，可多条 |
| `类型:` | 直流 / 相量 / 瞬态（不写则按子命令） |
| `ω:` 或 `f:` | 相量的角频率（rad/s）或频率（Hz） |
| `步长:` `时长:` `时刻:` `初值:` | 瞬态的 dt、tstop、采样时刻、初始 uC/iL |
| `变量:` `最小项:` `无关项:` `表达式:` `形式:` | 组合逻辑 |
| `触发器:` `Q序列:` / `状态转移:` | 时序逻辑 |

`求:` 的四种写法：`V(3)`（对地）、`V(2,3)`（节点差）、`I(R3)`（由 n1 经元件流向 n2 为正）、`I(Us)`（由 n1 经源流向 n2 为正）。

### 数值写法

- 直接写：`12`、`0.5`、`0.001`、`3/2`（分数也行）
- 工程后缀：`2k`=2000、`4.7k`=4700、`1M`=10⁶、`1m`=10⁻³、`10u`=10⁻⁶、`1n`=10⁻⁹
- 科学计数：`1e-6`、`2.2e3`
- 单位会被自动剥掉：`12V`、`2A`、`3Ω`、`5伏`、`3欧`、`100µF`、`1mH` 都认

## 命令速查

```bash
python circuit.py selftest             # 必跑一次：299 项金题回归，约 6 秒
python circuit.py card 题.card          # 直流 + 戴维宁 + 功率平衡自检
python circuit.py card 题.card --rl 3   # 端口接 3Ω 负载，算 u_L/i_L/P_L/P_max
python circuit.py card 题.card --json   # 机器可读输出
python circuit.py ac   题.card          # 相量（卡里写 ω: 或命令行 --w 1000 / --f 50）
python circuit.py ac   题.card --sweep 10,1e5,20   # 频响扫描
python circuit.py tran 题.card          # 瞬态（卡里写步长/时长，或命令行 --dt --tstop）
python circuit.py tran 题.card --at 1e-3,5e-3 --ic C1=3V
python circuit.py logic 题.logic        # 组合最简式 / 时序激励表或状态转移
python circuit.py deck  题.card         # 打印 SPICE 网表，可喂 ngspice 当第二意见
```

## 回复模板（五段，一段不许省）

1. **答案**：先给精确值 + 单位 + 符号含义（"负号表示实际方向与假设相反"）。形如 `u_oc = 500/9 V ≈ 55.6 V`。
2. **推导**：写清用了什么定理、列了哪几个方程。不必列出全部行列式，但要能复现。
3. **网表**：贴出题目卡。这是"我的判读"的书面凭证，用户能一眼看出极性有没有读反。
4. **验算证据**：把 `校验` 段贴出来（功率平衡、换参考点、戴维宁两条路径互校、往返）。**不许自己写"已验证"三个字就完事**。
5. **判读敏感性**：主动给一句"若某极性读反，答案会变成多少"。这一句最能防止用户拿错答案。

## 机器自检拦得住什么、拦不住什么

| 自检项 | 拦住什么 |
|---|---|
| 功率平衡 Σu·i 严格为 0 | 数值自洽但物理可疑（比如支路电流全 0、漏了某个源） |
| 换参考点复算 | 矩阵装配时节点索引错位 |
| u_oc / i_sc == R_eq | 戴维宁第三条腿算错（两条互不依赖的算法必须给同一个数） |
| 戴维宁等效 ≈ 原网络 | "等效"其实不等效（接上 R_L 后与原网络重解比对） |
| 网表往返 | 解析器丢元件、认错类型 |
| 相量功率平衡 Σù·î = 0 | 复阻抗的 j 符号搞反（L 与 C 互换是最常见的错） |
| 瞬态步长减半误差同减半 | 后向欧拉的实现有 bug（否则不会收敛） |
| 逻辑穷举 2ⁿ 全代入 | 化简结果与给定函数不一致 |

**拦不住的只有一样：你把题目卡写错了。** 所以第 3 段"网表"必须贴出来给人看。

## 踩坑清单（都是实测踩过的）

1. **端口不许跨理想电压源**。`端口: 3 0` 而 3-0 之间正好跨着一个 VCVS 或理想电压源，短路后两源并联，矩阵奇异。换个端口位置。（`golden/ex6.card` 的注释就写着这个：端口只能取 4-0，不能取 3-0。）
2. **R=0 不许写**。短路必须用 `V VSC a b 0V`，否则电流不可求、矩阵奇异。
3. **受控源必须保留**。求 R_eq 时独立源置零（V→0V 源、I→删掉），受控源一定要留——受控源是增益，不是激励。
4. **H/F 的控制量必须是具名电压源电流**，不能直接写"某电阻的电流"。用 0V 取样源。
5. **节点名一律当字符串**。别把 `0` 与 `"0"` 混用——这是母项目真实踩过的坑，会导致整列对不上、矩阵判奇异。
6. **相量的 L 与 C 最容易写反**：Z_L = jωL，Z_C = 1/(jωC) = −j/(ωC)。相量功率平衡的自检就是为这个准备的。
7. **瞬态必须给步长**，且步长至少比时间常数小两个数量级，否则后向欧拉的数值阻尼会把波形抹平。
8. **逻辑卡的"无关项"要和最小项一起进化简**，否则无关项等于没用上。

## 省 token 的做法

- **先跑 `selftest` 一次**（约 6 秒，输出两行）。全绿说明工具链可用，后面不必再怀疑工具。
- **不要为了理解而去通读 `circuit.py` 全文**（约 1800 行）。需要改行为时，用关键字定位：`parse_number`、`analyze_dc`、`branch_current`、`to_net`、`analyze_combo`。
- 用户只问一道题的答案时：写卡 → 跑一条命令 → 贴报告。**不要逐节点手算再复述一遍**，那是把同一件事做两遍。
- 大批量题（≥5 道）：写一个循环脚本一次跑完，只把 FAIL 的行挑出来看，不要逐题打印全文。
- `golden/` 里的 19 张卡是语法活样本。不确定某种元件怎么写时，看 `golden/ex6.card`（受控源全类型）、`golden/p4_14.card`（0V 取样源）、`golden/_syntax.card`（四种求法）、`golden/logic/` 四张逻辑卡。

## 目录说明

```
circuit-solving/
├── SKILL.md          本文件：判读方法、语法、命令、回复模板
├── circuit.py        求解器本体，纯标准库单文件，可直接复制到任意机器
├── golden/           金题回归：19 张卡 + expected.json 期望值
│   ├── *.card        15 张线性直流卡（含受控源全类型、戴维宁、变体）
│   ├── logic/*.logic 4 张逻辑卡（组合 2 + 时序 2）
│   └── expected.json 每张卡的逐节点电压、逐支路电流、待求量、戴维宁三参数
└── demo/             最小可跑示例（RLC 相量、RC 瞬态、非自启动状态机）
```

`circuit.py` 不依赖 `golden/`：把它单独拷到任何装了 Python 3 的机器上，`card`/`ac`/`tran`/`logic`/`deck` 五个子命令照常工作，只有 `selftest` 会因为找不到金题而只跑内置的解析式对拍。

## 做不了的（明说，别硬算）

- 非线性电路（二极管、晶体管工作点）：本工具只做线性。
- 运放的高阶非理想特性（压摆率、输入偏置电流）：只能用 VCVS 建有限增益模型。
- 从门级电路图反推逻辑式：需要人为读图，工具只接受变量+最小项/表达式。
- 带输入条件的状态表（`S0, X=0 → S0`）：工具只接受无条件的 `状态转移: a b`。
- 图片直读：实测电路图识别在斜置电桥这类拓扑上准确率很低（旋转 15° 后元件检测从 4/4 掉到 0/4），且不认受控源。**图是给你看的，不是给工具看的——必须由你转成文字卡。**
