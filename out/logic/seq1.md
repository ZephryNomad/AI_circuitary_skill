# 时序逻辑 JK 触发器激励序列

## 一、题意

- 触发器类型：JK
- 目标 Q 序列：[0, 1, 0, 0, 1, 0, 1]

## 二、逐拍激励（由现态与次态查激励表反推）

| 拍 | Qⁿ | Qⁿ⁺¹ | 需要的输入 |
|---|---|---|---|
| 1 | 0 | 1 | `J=1 K=X` |
| 2 | 1 | 0 | `J=X K=1` |
| 3 | 0 | 0 | `J=0 K=X` |
| 4 | 0 | 1 | `J=1 K=X` |
| 5 | 1 | 0 | `J=X K=1` |
| 6 | 0 | 1 | `J=1 K=X` |

## 三、校验

- 每一拍都用对应触发器的激励表反查，逐拍可复核；Q 序列首尾相接处即一次状态转移
