# 组合逻辑 由表达式写真值表并化简

## 一、题目给定的函数

- 变量：A B C（共 3 个，8 种输入）
- 来源：表达式 (A & B) | (~A & C)

## 二、卡诺图

```
      00  01  11  10
A \ BC
  0   0   1   1   0
  1   0   0   1   1
```

## 三、最简式

- **最简与或式（SOP）：** `F = (A & B) | (C & ~A)`
- **最简或与式（POS）：** `F = (A | C) & (B | ~A)`

## 四、门数统计（按 SOP 式）

| 与门 | 或门 | 非门 | 合计 |
|---|---|---|---|
| 2 | 1 | 1 | **4** |

## 五、两级与非实现

```
N1   = NAND(A,B)  → ¬(A·B)
N2   = NAND(A,A)  反相器，得 ¬A
N3   = NAND(C,N2)  → ¬(C·N2)
F    = NAND(N1,N3)  → F

与非门总数：**4**（其中反相器 1 个）
```

## 六、穷举校验

- **通过**：8 种输入逐点代入，最小项全为 1、非最小项全为 0，SOP 与 POS 各自成立（无关项不参与约束）
