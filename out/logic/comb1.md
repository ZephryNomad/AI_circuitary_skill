# 组合逻辑 四变量卡诺图化简（带无关项）
> 教材典型题：用卡诺图求最简与或式，无关项可任意取 0 或 1

## 一、题目给定的函数

- 变量：A B C D（共 4 个，16 种输入）
- 来源：最小项 m(0,1,2,5,8,9,10) + d(3,11,14,15)

## 二、卡诺图

```
       00  01  11  10
AB \ CD
  00   1   1   X   1
  01   0   1   0   0
  11   0   0   X   X
  10   1   1   X   1
```

## 三、最简式

- **最简与或式（SOP）：** `F = ~B | (D & ~A & ~C)`
- **最简或与式（POS）：** `F = (D | ~B) & (~A | ~B) & (~B | ~C)`

## 四、门数统计（按 SOP 式）

| 与门 | 或门 | 非门 | 合计 |
|---|---|---|---|
| 1 | 1 | 3 | **5** |

## 五、两级与非实现

```
N1   = NAND(A,A)  反相器，得 ¬A
N2   = NAND(C,C)  反相器，得 ¬C
N3   = NAND(D,N1,N2)  → ¬(D·N1·N2)
F    = NAND(B,N3)  → F

与非门总数：**4**（其中反相器 2 个）
```

## 六、穷举校验

- **通过**：16 种输入逐点代入，最小项全为 1、非最小项全为 0，SOP 与 POS 各自成立（无关项不参与约束）
