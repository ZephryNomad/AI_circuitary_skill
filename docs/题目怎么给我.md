# 题目怎么给我 —— 电路 / 模拟 / 数字 三类题的输入规范

一句话：**图片可以直接发，但要顺带说清「极性、方向、求什么」；数字电路最好直接给真值表或状态表。**

下面的每一条"支持/不支持"都是在本仓库里实跑验证过的，不是推测。
支撑这些结论的探针网表（每个能力一条 `.cir`）留在 `tools/_scratch/probe_能力探测/`，可随时复查。

## 一、总览：什么题走哪条路

| 题型 | 你给我 | 我用什么算 | 精度 | 自检强度 |
|---|---|---|---|---|

## 二、模拟电路 / 电路原理

### 2.1 发图片时，请顺带交代这 5 件事

图片我能读（会做像素级放大取证），但**符号的极性靠像素判断，有歧义时误差会直接传到答案**。所以最省事的做法是：图片 + 一句话确认这 5 项。

1. **电压源的 "+" 在哪一端**（上/下/左/右）
2. **电流源的箭头朝哪**（朝上=由地流入上端节点；朝下=由上端节点流入地）
3. **受控源的参考极性**（菱形旁 `+ 2I₁ −` 是 + 在左还是 + 在右）
4. **待求量的参考方向**（图上那个 `I` 箭头由谁指向谁）
5. **求什么**（求某支路电流 / 求某点电压 / 求戴维宁等效 / 求 R_L 最大功率）

真实案例：习题 4-14 里，受控源极性读反会让答案从 **P_max = 108 W** 变成 **84.5 W**（R_eq 从 3 Ω 变 2 Ω）。这类量必须锁死。

> 图上如果字太糊，我会自己放大到认不出为止再问你，不会拿猜测往下算。

### 2.2 直接写文字时，按这个顺序

```
① 拓扑：谁接谁（"8V 正极朝上，经 4Ω 到节点 A；A 经 4Ω 到地；A 经 1Ω 到 B……"）
② 数值：每个元件多少
③ 方向：电源极性与待求量参考方向
④ 求什么：求 I / 求 U / 求戴维宁 / 求最大功率
```

### 2.3 数值和单位的写法（有坑，照抄下面的）

| 写法 | 是否接受 | 说明 |
|---|---|---|
| `12`、`0.5`、`3/2`、`0.001` | ✅ | 分数会被当成分数精确处理 |
| `2k`、`1K`、`4.7k` | ✅ | k = 10³ |
| `1M` | ✅ | **M = 10⁶（兆）**，不是毫 |
| `12V`、`2A`、`3Ω`、`1kΩ`、`5伏`、`3欧` | ✅ | 单位只剥除、不换算 |
| `1m`、`10u`、`1n`、`1meg`、`1e-6`、`10mV`、`10uF` | ❌ | 报「无法识别数值」 |

**小数值请写小数**：10 mV 写 `0.01V`，1 μF 写 `0.000001`（或交给 ngspice 那侧直接写 `1u`）。

### 2.4 支路电流的正负约定（我会按这个报数）

- 电阻 `R n1 n2`：电流以「由 n1 经元件流向 n2」为正
- 电压源 `V n1 n2 v`：`v` 是 V(n1) − V(n2)，**n1 是正极**；源电流以「由 n1 经源流向 n2」为正

## 三、数字电路

### 3.1 组合逻辑（化简 / 卡诺图 / 门数 / 与非实现）

给我这三样就够：

- **变量名**（`A B C D`）
- **最小项**，有无关项一起给
- **要什么形式**（最简与或 SOP / 最简或与 POS / 两级与非）

也可以直接给表达式，这些写法都能吃：
`(A & B) | (~A & C)`、`A·B + ~A·C`、`NOT A AND B`、`A ^ B`、`A ⊕ B`

输出会包含：卡诺图、最简式、门数统计、两级与非实现、**2ⁿ 全输入穷举校验（违例必须为 0）**。

### 3.2 时序逻辑

**两种给法，选一种：**

- **给激励**：`触发器: JK` + `Q序列: 0 1 0 0 1 0 1` → 我反推每一拍要什么输入
  （触发器支持 **D / T / JK / RS**，四种都实测过）
- **给状态表**：`状态转移: 0 1 / 1 2 / 2 0 / 3 1` → 我走出状态序列、找闭环、判**自启动**

### 3.3 数字电路目前做不了的

- **带输入条件的状态表**（如 `S0, X=0 → S0`）——当前 `状态转移:` 只能写「现态 次态」两列。这类题请把状态转移表写成**两列形式**，或者直接给状态方程。
- 从**门级电路图**自动反推逻辑式 —— 没有这个能力（SINA 那条路只覆盖模拟原理图的元件与连线，且不含受控源）。

## 四、复制即用的模板

**模拟题：**

```
题名: 习题 4-14
求: R_L 取何值获得最大功率；并求 P_max
① 6A 电流源：圆内水平直径，箭头朝上（由地流入上轨左端），标 6A
② 上轨左端经 4Ω 到节点 M；M 经 16V 源到地，16V 的 + 在上
③ M 经受控源菱形到节点 B；菱形上方标「− 2I₁ +」（− 在左、+ 在右）
④ B 经 6Ω 到地；6Ω 上标 I₁，箭头向下
⑤ B 经 6V 源到节点 C，6V 的 + 在右

```

```
最小项: 0 1 2 5 8 9 10
无关项: 3 11 14 15
形式: SOP
```

**数字题（时序）：**

```
类型: 时序
触发器: JK
Q序列: 0 1 0 0 1 0 1
```

## 五、我会怎么回你

1. **答案**（精确值，带符号方向说明，如"−0.4 A，实际由 B 流向 A"）
2. **推导过程**（等效变换 / 戴维宁三步 / 卡诺图圈组）
3. **网表**（可直接喂 LTspice / ngspice 的 `.cir`）
4. **验算证据**：几条互不依赖的通道各自得出同一个数（精确 MNA、ngspice、手算、独立 numpy），外加功率平衡或穷举校验
5. **判读敏感性**：如果某个极性存在第二种读法，我会把"若读反则答案是多少"一并列出，你自己对书上答案一眼就能定

## 七、图片 → 网表这条路的现状（别指望它）

SINA（arXiv 2607.01609）我拿真模型在讲义插图上跑过：**36/46 = 78.3%**（论文称 96.67%）。分组看——横平竖直的网络 **20/20 全中**，斜置电桥 **2/10**。把一张图旋转 15°，电阻检测从 4/4 掉到 0/4。

另外它**只认 10 类元件，没有任何受控源**；PCB 分支的 `spice.py` 把所有二引脚元件一律写成 `1k` 占位、不带真实数值。

所以：**图片是给我看的，不是给模型看的。** 我读图 + 你确认极性，比等一个 78% 的管道可靠得多。
