# 第 6 章　最大功率传输

## 6.1 问题

戴维宁等效电路最常见的用途之一：给定一个单口网络，问**负载取多大时能从网络获得最大功率**。

这个问题之所以能一句话回答，正是因为等效电路已经把网络压缩成了两个数。若不用等效，每换一个负载都要重解全网；用了等效，问题变成一个单变量函数求极值。

![图 6-1　戴维宁等效电路接外接负载](figs/fig14_thevenin_load.png){width=84%}

## 6.2 推导

等效电路里，电源 $u_{oc}$ 与 $R_{eq}$ 串联，外接 $R_L$。负载电流

$$i_L=\frac{u_{oc}}{R_{eq}+R_L}$$

负载功率

$$P_L=i_L^2R_L=\frac{u_{oc}^2R_L}{(R_{eq}+R_L)^2}$$

把 $P_L$ 看作 $R_L$ 的函数（$u_{oc}$、$R_{eq}$ 视为常数），求导：

$$\frac{dP_L}{dR_L}=u_{oc}^2\cdot\frac{(R_{eq}+R_L)^2-2R_L(R_{eq}+R_L)}{(R_{eq}+R_L)^4}=u_{oc}^2\cdot\frac{R_{eq}-R_L}{(R_{eq}+R_L)^3}$$

令导数为零：

$$R_L=R_{eq}\text{　　　　}(6-1)$$

此时

$$P_{\max}=\frac{u_{oc}^2R_{eq}}{(2R_{eq})^2}=\frac{u_{oc}^2}{4R_{eq}}\text{　　　　}(6-2)$$

对应的端口电压和电流：

$$u_L=\frac{u_{oc}}{2},\text{　　} i_L=\frac{i_{sc}}{2}$$

## 6.3 图形直觉

![图 6-2　$u_{oc}=4\ \text{V}$、$R_{eq}=2\ \Omega$ 时的负载功率曲线，峰值出现在 $R_L=R_{eq}$](figs/fig16_power_curve.png){width=78%}

曲线的形状值得记住：

- $R_L=0$（短路）：$P_L=0$，因为电压为零；
- $R_L\to\infty$（开路）：$P_L\to 0$，因为电流为零；
- 中间必有一个峰值，位于 $R_L=R_{eq}$；
- 曲线在**对数尺度上左右对称**。把 $R_L$ 换成 $\dfrac{R_{eq}^2}{R_L}$（即“把 $R_L$ 与 $R_{eq}$ 的比值取倒数”），功率不变。所以 $R_L=2R_{eq}$ 和 $R_L=R_{eq}/2$ 的功率相同，都是 $P_{\max}$ 的 $\dfrac{8}{9}\approx 89\%$。这意味着匹配点附近的功率曲线**很平缓**——$R_L$ 偏离一倍只损失 11%，这也是实际工程里对阻抗匹配精度要求不高的原因之一。

## 6.4 一个必须澄清的误解

教材上常写“最大功率传输定理：负载电阻等于电源内阻时获得最大功率”。很多同学由此产生两个误解：

**误解一：$R_L=R_{eq}$ 是效率最高的工作点。**
不是。此时电源发出的总功率是 $\dfrac{u_{oc}^2}{2R_{eq}}$，负载得到 $\dfrac{u_{oc}^2}{4R_{eq}}$，**传输效率恰好 50%**，另一半消耗在 $R_{eq}$ 上。电力系统追求高效率，所以发电机内阻远小于负载，绝不会工作在匹配点。匹配只在**信号传输**（通信、音频、射频）里才是目标，因为那里关心的是“送到负载的功率有多大”，而不是“效率有多高”。

**误解二：$R_L=R_{eq}$ 时端口电压最大。**
不是。端口电压 $u_L=u_{oc}\dfrac{R_L}{R_{eq}+R_L}$ 随 $R_L$ 单调增，开路时最大（等于 $u_{oc}$），但那时功率为零。**电压最大和功率最大是两个不同的目标。**

| 目标 | 条件 | 结果 |
|:---|:---|:---|
| 负载功率最大 | $R_L=R_{eq}$ | $P_{\max}=\dfrac{u_{oc}^2}{4R_{eq}}$，效率 50% |
| 负载电压最大 | $R_L\to\infty$ | $u_L\to u_{oc}$，功率趋零 |
| 负载电流最大 | $R_L\to 0$ | $i_L\to i_{sc}$，功率趋零 |
| 传输效率最高 | $R_L\gg R_{eq}$ | 效率趋近 100%，功率趋零 |

## 6.5 例题

**例 1 续**：$u_{oc}=4\ \text{V}$、$R_{eq}=2\ \Omega$。

$$P_{\max}=\frac{4^2}{4\times 2}=2\ \text{W}\text{　}(R_L=2\ \Omega)$$

接 $R_L=2\ \Omega$ 时实测 $P_L=2\ \text{W}$，正好等于 $P_{\max}$，符合预期。

**若接 $R_L=6\ \Omega$**：

$$i_L=\frac{4}{2+6}=0.5\ \text{A},\text{　　} P_L=0.5^2\times 6=1.5\ \text{W}$$

只有 $P_{\max}$ 的 75%。虽然效率提高到 $\dfrac{1.5}{4\times 0.5}=75\%$，但送给负载的功率下降了。

这个对比很说明问题：**最大功率点和最高效率点不是同一个点**。做题时必须看清楚题目问的是哪一个。

## 6.6 适用条件

$R_L=R_{eq}$ 这个结论成立有前提：

1. $u_{oc}$、$R_{eq}$ 都是**常数**（即网络是线性的，且 $R_{eq}$ 与 $R_L$ 无关）；
2. $R_L$ 可以**自由调节**；
3. $R_{eq}>0$（若 $R_{eq}<0$，$P_L$ 无上界，匹配条件失去意义）。

如果 $R_L$ 只能取有限几个值，那就直接算每个值下的 $P_L$ 比大小，不要套公式。
