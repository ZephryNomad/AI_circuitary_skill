# 电路题目 → 网表 工具链

把电路原理题目（戴维宁、节点法、网孔法……）写成 **SPICE 网表**，并当场精确求解、双向核对。

## 为什么需要它

题目转网表这件事，手抄和手推犯错的概率一样高。所以这里做成**可验证**的：

```
题目卡(.card)  →  SPICE 网表(.cir)  →  再解析回来  →  精确求解  →  三方比对
```

任何一环抄错，比对就会失败。

## 三层结构

| 文件 | 职责 |
|---|---|
| `tools/netlist.py` | 纯文本层：题目卡 ↔ SPICE 网表双向转换，不算数 |
| `tools/mna.py` | 纯求解层：精确有理数 MNA + 戴维宁参数提取 |
| `tools/convert.py` | 驱动层：串联上面两层，生成报告，做往返自检 |
| `tools/spice_check.py` | 第三方校验：调真实 ngspice 算同一张网表并比对 |
| `tools/answer_key.py` | 答案校验：与讲义写定的答案逐题比对 |

## 快速开始

```bash
# 单题：生成报告
python tools/convert.py netlists\ex3.card

# 全部题目：批量生成 + 自检 + 写盘
python tools/convert.py netlists --all --selftest --outdir out\netlists

# 指定负载电阻，一并算 u_L / i_L / P_L / P_max
python tools/convert.py netlists\hw1.card --rl 3

# 第三方校验（需 ngspice）
python tools/spice_check.py netlists\ex1.card netlists\ex3.card

# 与讲义答案比对
python tools/answer_key.py --verbose
```

## 题目卡语法

```
题名: 例3 不平衡电桥
端口: 2 3                      # 戴维宁端口 a=2, b=3；省略则只做直流分析、不求等效
求: R3                         # 待求量，可多行；省略则只给全网表与节点电压
备注: 任何说明                  # 可多行

V Us 1 0 12V                   # 电压源 V(1)-V(0)=12，1 是 + 极
R R1 1 2 1Ω                    # 电阻
I Is 0 1 2A                    # 电流源：2A 由 0 经源流向 1
E E1 4 0 2 0 2                 # VCVS：V(4)-V(0) = 2·(V(2)-V(0))
G G1 3 0 2 0 1                 # VCCS：由 3 经源流向 0 的电流 = 1·(V(2)-V(0))
H H1 3 0 Us 3                  # CCVS：V(3)-V(0) = 3·I(Us)
F F1 4 0 Us 2                  # CCCS：由 4 经源流向 0 的电流 = 2·I(Us)
```

要点：
- **名字可省**：`R 1 2 1Ω` 会自动编号成 `R1`。
- **名字会自动补位号**：写 `Us` 会存成 `VUs`（SPICE 靠行首字母判类型），原标签保留在注释里。
- **数值精确**：支持 `12`、`0.5`、`3/2`、`2k`、`1M`，可带单位 `V A Ω 伏 安 欧`（只剥除不换算）。全程用有理数，不引入浮点误差。
- **控制源**：`H`/`F` 只能由**独立电压源**的电流控制，且该电压源必须有名字。
- **`求:` 行的四种写法**（也可写 `求取:` / `find:`）：

  | 写法 | 含义 |
  |---|---|
  | `求: R3` 或 `求: I(R3)` | 元件 `R3` 的支路电流，按「由 n1 经元件流向 n2」为正面值 |
  | `求: V(3)` | 节点 3 对地的电压 |
  | `求: V(2,3)` | 节点 2 与节点 3 之间的电压差 V(2)−V(3) |
  | `求: I(Us)` | 具名电压源支路的电流（`I>0` 表示由 n1 经源流向 n2） |

  没有 `端口:` 行也能单独用 `求:`——此时只做直流分析，不计算戴维宁等效。

  `_syntax.card` 就是这四行的回归卡，已纳入 `--all` 自检：改动 `netlist.py` 的解析分支后，
  若语法被改坏，批量自检会当场失败。

## 数值约定（易错，务必对照）

| 元件 | 约定 |
|---|---|
| 电压源 `V n1 n2 v` | V(n1) − V(n2) = v，**n1 是正极** |
| 电流源 `I n1 n2 i` | i > 0 表示电流由 n1 **经源**流向 n2 |
| 受控源 `E/G n1 n2 c1 c2 k` | 输出端 n1-n2，受 c1-c2 的控制量控制 |
| 戴维宁端口 `端口: a b` | u_oc = V(a) − V(b)；i_sc 由 a 经短路线流向 b |

## 生成的报告包含四部分

1. **元件清单与网表对照**——每个元件的中文描述与对应 SPICE 语句
2. **SPICE 网表**——可直接喂给 LTspice / ngspice
3. **独立复算**——精确有理数解的节点电压、u_oc、i_sc、R_eq、负载量
4. **自检**——往返一致性与 u_oc/i_sc = R_eq 校验

## 验证强度（这不是"应该对"，是跑过的）

三层验证，全部实跑：

| 验证 | 内容 | 结果 |
|---|---|---|
| 往返自检 | 题目卡→网表→解析回来，元件与值完全一致 | 15/15 通过 |
| ngspice 交叉 | 同一张网表交给工业级 ngspice 独立求解，节点电压逐个比对 | 15/15 一致 |

换机器后若找不到，`spice_check.py` 会自动在 PATH 和常见安装路径里找。

## 已知限制

- `convert.py` 只覆盖**直流稳态**：没有 C/L 的瞬态、没有交流相量、没有非线性器件（二极管/晶体管）。
  - **相量**可直接调 `mna.py`：把 `('R', n1, n2, j*ω*L)`、`('R', n1, n2, 1/(j*ω*C))` 当阻抗传进去，
    同一套 MNA 就解正弦稳态（实测 RLC 串联得 `[1, 0, -I]`，戴维宁得 `u_oc=-j`、`R_eq=10-10j`）。
  - **非线性 / 瞬态 / 交流 / 扫描**走 `tools/spice_run.py 网表.cir`，由真实 ngspice 计算。
- 端口 a、b 之间若正好跨着一个理想电压源，短路步骤会变成两个理想电压源并联（矩阵奇异）。
  此时 `convert.py` 会给明确报错而不是崩栈。**同理，运放用 VCVS 建模时不要写 `端口:` 行**
  （输出端本身就是理想电压源），只写 `求: V(n)` 即可。
- 数值后缀只认 `k` `K` `M`（M = 10⁶，**不是毫**）：`1m`、`10u`、`1n`、`1e-6`、`10mV` 一律报错，
  小数值请写 `0.01` 这样的十进制或 `1/100` 分数。
- 网表生成是**人工写题目卡**，不是从图片识别。图片→网表的实测结论见 `tools/probe_sina.py`。
- 数字电路不在 `.card` 体系里，另用 `tools/logic.py` + `.logic` 卡（见 `netlists/logic/`）。
